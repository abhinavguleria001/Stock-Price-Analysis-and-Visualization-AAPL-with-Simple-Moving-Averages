# Stock-Price-Analysis-and-Visualization-AAPL-with-Simple-Moving-Averages
This project analyzes the stock prices of Apple Inc. (AAPL) using Python. It fetches historical stock data and calculates three key Simple Moving Averages (SMA): 20-day, 50-day, and 200-day. The analysis provides insights into stock price trends and helps in understanding market behavior over different time frames.
